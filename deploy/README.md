# Развёртывание на своём сервере

Полная пошаговая инструкция находится в [основном README](../README.md#запуск-на-своём-сервере-и-домене).

- `Caddyfile` — HTTPS и проксирование на Python API; домен задаётся через `SITE_DOMAIN`.
- `backup.sh` — согласованная резервная копия SQLite в `backups/`, хранение 7 дней. Запускается из любой директории, использует `compose.production.yaml`. Для локального запуска: `COMPOSE_FILE=compose.yaml ./deploy/backup.sh`.
- `compose.production.yaml` находится в корне проекта. Приложение и Caddy работают в отдельных контейнерах, наружу публикуются только порты Caddy 80/443.

Персональные адреса серверов, пароли, рабочая база, резервные копии и SSH-ключи в репозиторий не включаются.
